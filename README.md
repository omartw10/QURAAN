## 1. وصف المشروع

**رحلة هداية** منصّة ويب إسلامية مبنية بـ **HTML5 و CSS3 و JavaScript خالص** (دون أي إطار عمل أو أدوات بناء)، تتيح للمستخدم:

- الاستماع إلى **القرآن الكريم** بأصوات نخبة من القرّاء وبروايات متعددة، مع جلب البيانات حيًّا من واجهة برمجية حقيقية.
- متابعة **البث المباشر** للحرم المكي الشريف.
- قراءة **آية اليوم** مع تفسيرها، تتجدّد عشوائيًا عبر واجهة برمجية.
- **التواصل** عبر نموذج تفاعلي مع تحقّق فوري من المدخلات.

> صُمِّم المشروع بهوية بصرية هادئة (أخضر زمردي + ذهبي) تناسب الطابع الديني، مع دعم كامل للغة العربية (RTL) ووضع ليلي مريح للعين.

## 2. أبرز المميزات

| الميزة | الوصف |
| :--- | :--- |
| 🎧 **مشغّل قرآن ديناميكي** | اختيار القارئ ← الرواية ← السورة، مع تشغيل وإيقاف وتحكّم كامل |
| 🔎 **بحث ذكي** | بحث في القرّاء والسور يتجاهل التشكيل واختلاف الهمزات |
| ⏩ **تحكّم متقدّم بالصوت** | شريط تقدّم من اليمين لليسار، تقديم/تأخير ١٠ ثوانٍ، مؤشّر تحميل |
| 📺 **بث مباشر** | تضمين البث الحي للحرم المكي مع رابط احتياطي |
| 📖 **آية اليوم** | آية عشوائية مع تفسيرها الميسّر عبر API |
| ✉️ **نموذج تواصل** | تحقّق فوري من الاسم والبريد والرسالة |
| 🌙 **وضع ليلي/نهاري** | يُحفظ تلقائيًا ويُطبّق قبل رسم الصفحة لمنع الوميض |
| 📱 **تصميم متجاوب** | يعمل بسلاسة على الجوال والأجهزة اللوحية والحاسوب |

## 3. الصفحات

| الصفحة | الغرض | أهم المحتويات |
| :--- | :--- | :--- |
| `index.html` | الواجهة الرئيسية | مشغّل الصوت + بطاقات تنقّل + قسم "آية اليوم" |

---

## 4. التقنيات المستخدمة

- **HTML5** — هيكلة دلالية (Semantic Markup).
- **CSS3** — تنسيق بـ Flexbox و Grid، ومتغيّرات CSS لإدارة السمات، ومنهجية تسمية **BEM**.
- **Vanilla JavaScript (ES6+)** — إدارة DOM، الاتصال بالـ APIs عبر `fetch`/`async-await`، والتحقّق من المدخلات.
- **Font Awesome 6** و**خطوط Google** (Amiri و Tajawal) عبر CDN.

## 7. طريقة التشغيل

1. حمّل المشروع وافتح المجلد.
2. **الطريقة المُوصى بها** — شغّله عبر خادم محلي لضمان عمل جميع الميزات:
   - في VS Code: ثبّت إضافة **Live Server**، ثم انقر بزر الفأرة الأيمن على `index.html` ← *Open with Live Server*.

> ⚠️ **ملاحظة مهمة:** يجب تشغيل الموقع عبر `http`/`https` (خادم محلي أو الرابط المنشور) وليس بفتح الملف مباشرة (`file://`)، لأن البث المباشر من يوتيوب لا يعمل عبر بروتوكول الملفات.

---

## 8. النشر المباشر

المشروع مهيّأ للنشر على **Vercel** عبر ملف `vercel.json`:

1. ارفع المشروع إلى مستودع على **GitHub**.
2. من **Vercel**: *Add New Project* ← اختر المستودع ← *Deploy*.
3. لا يحتاج المشروع إلى أمر بناء (موقع ثابت)، ويعمل البث المباشر تلقائيًا لأنه يُقدَّم عبر `https`.

---

## 9. سهولة الوصول والتجاوب

- **سهولة الوصول:** سمات `aria-label` و`title` وصفية لكل الأزرار، ووسوم `<label for="...">` مرتبطة بكل حقل.
- **التجاوب:** تصميم مرن عبر Grid و Flexbox مع نقاط تحوّل عند `768px` و`420px`.
- **تقليل الحركة:** احترام تفضيل `prefers-reduced-motion` لإيقاف التأثيرات تلقائيًا.
- **اتجاه RTL:** الموقع كامل من اليمين إلى اليسار بما في ذلك شريط تقدّم الصوت.
