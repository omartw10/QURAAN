## 1. وصف المشروع
منصة ويب إسلامية تفاعلية مبسطة (Minimalist) تتيح للمستخدم الاستماع إلى القرآن الكريم بجودة عالية بصوت كوكبة من مشاهير القراء وبالروايات المختلفة، إلى جانب متابعة البث المرئي المباشر لقناتي القرآن الكريم والسنة النبوية من الحرمين الشريفين.

## 3. دوافع المشروع والمشكلة التي يحلها
يكمن الدافع في تقديم مشروع جامعي يلتزم بأعلى معايير هندسة الكود وتطبيق مبدأ **فصل المهام (Separation of Concerns)**. يحل المشروع مشكلة المواقع القرآنية التقليدية التي تعتمد على بيانات وهمية ثابتة، ويوفر واجهة مستخدم هادئة خالية من التشتت البصري والإعلانات المزعجة.

---

## 4. حالة المشروع قبل وبعد التطوير

| ما كان موجوداً سابقاً | ما تم تعديله / إضافته | الإجراء |
| :--- | :--- | :--- |
| ملف واحد عشوائي `index.html` | تقسيم المشروع إلى هيكل متعدد الصفحات (Multi-page) | إعادة بناء كاملة |
| كود JS مدمج داخلياً | فصل الأكواد إلى ملفات منظمة وسهلة الصيانة | فصل وتنظيم |
| ملف `Style.css` غير منظم وبألوان عشوائية | استخدام نظام لوني بني/ذهبي وتطبيق كلاسات BEM | إعادة بناء بصري |
| مشغل صوت بمؤقت زائف وبيانات وهمية | ربطه بـ REST API حقيقي وتتبع التشغيل بدقة | ربط ديناميكي |
| بث مباشر معطل برموز خطأ (Error 153) | استخدام كود تضمين رسمي مستقر من قنوات يوتيوب | إصلاح وتطوير |

## 5. الصفحات والمحتوى

| اسم الصفحة | الغرض | المحتوى الرئيسي |
| :--- | :--- | :--- |
| `index.html` | الواجهة الأساسية والمشغل | مشغل القرآن، قوائم اختيار القارئ/الرواية/السورة، تأثير ذبذبات الصوت |

## 6. التقنيات المستخدمة

- **HTML5:** لبناء هيكل الصفحات الدلالي (Semantic Markup).
- **CSS3:** لتنسيق الواجهات باستخدام Flexbox و Grid، واستخدام متغيرات CSS للنمط الداكن.
- **Vanilla JavaScript (ES6+):** لإدارة الـ DOM، الاتصال بالـ APIs، والتحقق الفوري من المدخلات.
- **Font Awesome (v6.4.0):** كـ CDN لعرض الأيقونات التفاعلية.

## 8. طريقة التشغيل

1. قم بتحميل أو فك ضغط مجلد المشروع.
2. لتشغيل الموقع محلياً، انقر نقراً مزدوجاً فوق ملف `index.html` لفتحه مباشرة في أي متصفح.
3. للحصول على أفضل أداء للـ Fetch والتحقق من جلب البيانات، يفضل تشغيله عبر خادم محلي مثل إضافة **Live Server** في محررات الأكواد (VS Code).

---

## 9. الـ APIs ومصادر البيانات

تم دمج منصة **MP3Quran API** (الإصدار v3) لجلب البيانات حركياً:
* **رابط جلب القراء:** `https://www.mp3quran.net/api/v3/reciters?language=ar`
* **رابط جلب السور:** `https://www.mp3quran.net/api/v3/suwar?language=ar`
* **الغرض:** جلب قائمة القراء وتصنيف الروايات المتاحة لهم، ثم جلب رابط الخادم السحابي لكل قارئ لتشغيل السور بصيغة MP3.

## 10. شرح أجزاء مهمة من الكود

### أ) التحقق الفوري من صحة البريد الإلكتروني (Form Validation)
```javascript
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
if (!emailRegex.test(value)) {
  return { isValid: false, message: 'صيغة البريد الإلكتروني غير صالحة. مثال: name@example.com' };
}
```
* **الشرح:** نستخدم تعبيراً نمطياً (Regex) للتحقق من صحة صياغة البريد المدخل فور قيام المستخدم بالكتابة، وتنبيهه مباشرة في حال وجود خطأ قبل ضغط زر الإرسال.

### ب) تصفية السور المتاحة حركياً (Dynamic Surah Filtering)
```javascript
const allowedSurahIds = moshaf.surah_list.split(',').map(s => parseInt(s, 10));
const filteredSuwar = suwarData.filter(s => allowedSurahIds.includes(s.id));
```
* **الشرح:** نظراً لأن بعض القراء لم يسجلوا المصحف كاملاً، نأخذ مصفوفة السور المسجلة فقط من خادم الـ API ونقوم بفلترة القائمة وعرض السور المتاحة لهذا القارئ بعينه فقط لتجنب تشغيل روابط تالفة.

### ج) إدارة المظهر الداكن وحفظ التفضيل (Dark/Light Mode)
```javascript
const savedTheme = localStorage.getItem('theme');
const initialTheme = savedTheme || (systemPrefersDark ? 'dark' : 'light');
document.documentElement.setAttribute('data-theme', initialTheme);
```
* **الشرح:** نقوم بفحص ذاكرة المتصفح للتعرف على الوضع الذي فضله المستخدم سابقاً، أو نعتمد خيار نظام التشغيل الافتراضي ونطبقه عبر وسوم CSS المخصصة.

## 11. سهولة الوصول والتجاوب
* **سهولة الوصول (Accessibility):** تم تزويد جميع الأزرار والروابط بـ `aria-label` و `title` وصفيين، واستعمال وسوم التسمية المرتبطة `<label for="...">`.
- **التجاوب (Responsive Breakpoints):** تصميم مرن باستخدام شبكة Grid وتوافق تام مع الشاشات الصغيرة (أقل من 768px) للموبايل والأجهزة اللوحية.
- **تقليل الحركة:** احترام تفضيلات المستخدم الخاصة بتقليل الحركة (`prefers-reduced-motion`) لإيقاف التأثيرات البصرية تلقائياً.

---

## 12. طريقة التعديل والتخصيص
* **لتغيير الألوان العامة:** قم بتعديل قيم المتغيرات اللونية المقررة في `:root` بأعلى ملف `css/main.css`.
* **لإضافة قارئ جديد:** يتم التحديث تلقائياً بمجرد إضافته من قبل خادم الـ API، ولا يتطلب كوداً إضافياً.

## 13. التحديات وحلولها
* **التحدي:** مشكلة كسر التشغيل (CORS) عند تشغيل ملفات HTML محلياً عبر بروتوكول `file:///`.
  - **الحل:** تم بناء وتضمين أجزاء الموقع (Header & Footer) محلياً وثابتاً في كل صفحة بدلاً من استدعائها الخارجي، لضمان تشغيل وعمل كامل صفحات الموقع أمام لجنة التقييم بدون اشتراط وجود سيرفر محلي.
